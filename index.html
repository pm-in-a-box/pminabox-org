The idea is simple

Your software should follow the way the company already works.

Accounting should have accounting work. Leasing should have leasing work. Private work should stay private. PM in a Box starts there, then adds the agents and automation each team actually needs.

Inside the box

Built around the work, not the AI.

Every feature belongs to a real place in the operation. The result feels less like a chatbot and more like the company workspace.

01

Departments that work like rooms

Give Accounting, Leasing, Maintenance, Operations, Marketing, and Engineering their own chat, members, agents, model, connectors, and work surfaces.

  • Shared chat
  • Threads
  • Files
  • Voice calls
02

AI agents with a clear job

Add agents to the department where they work. Attach focused skills, choose a model, and @mention an agent when you need it. Agents use only the context and connectors available in that room.

  • Agent skills
  • Multiple models
  • Visible tool use
03

Boards for work that has to get done

Track tasks by stage, owner, assignee, due date, and department. Add subtasks, comments, attachments, property links, and reusable templates. My Tasks brings each person's work into one list.

  • Task boards
  • Templates
  • My Tasks
04

Email and calendars beside the conversation

Read and reply to shared mail, create events, check availability, and keep the surrounding team context nearby. Google Workspace and Microsoft 365 stay scoped to the right department or person.

  • Shared inbox
  • Calendar
  • Direct messages
05

Automations your team can see

Build flows from email and task events. Add conditions, AI steps, web research, messages, drafts, and task actions. Test a flow before turning it on, then inspect each run when something needs attention.

  • Visual builder
  • Dry runs
  • Run history
06

Private tools built for your company

Ask Engineering to build a Box App against approved department data. Review a draft, set who can view or operate it, and publish the exact version your team should use.

  • Scoped data
  • Permissions
  • Audited actions
07

A website studio inside Marketing

Start from the company website, ask for changes in plain English, compare versions, preview the result, and publish when it is ready. Custom-domain controls stay with owners and admins.

  • Site import
  • Version history
  • Publishing
08

A private workspace for each person

Personal AI, private connectors, notification controls, drafts, and direct messages stay separate from shared department work. Owners can see adoption and the work inbox without opening private conversations.

  • Personal AI
  • Private connectors
  • Notifications

Made for the actual portfolio

Useful on Monday morning.

No generic AI promises. These are the jobs the box is designed to help with.

Accounting

Find the exception before month-end.

Reconcile bank activity, check trust balances, draft owner statements, and build portfolio reports with the source data attached.

Leasing

Move the next decision forward.

Summarize leases, draft notices and renewals, review the inbox, find calendar time, and keep follow-up work on the board.

Maintenance

Keep the request and the work together.

Triage incoming issues, connect work orders to properties, dispatch vendors, collect attachments, and track completion.

Leadership

See the work without reading every chat.

Review My Tasks, department activity, employee adoption, app permissions, connector audiences, and portable data exports.
