What the agents do

Agents that finish the job.

Not a chat window with a property management theme. These are the behaviors that make an agent worth keeping around for a month.

01

They remember what matters

Tell an agent your preferences, your style, or how your portfolio works and it keeps that instead of asking again next week. Stale notes get pruned, and a standing instruction becomes a routine that actually runs.

02

They run on a schedule

Ask for a Monday morning summary or a weekday debrief and the agent sets up the routine itself. Open its details to see what is scheduled, run it now, pause it, or delete it.

03

They hand work to each other

A manager agent can brief the whole team at once without sitting and waiting. Every hand-off appears as a card in the chat you can open to read exactly what was asked and what came back.

04

They read your connected systems

Agents try the live system first and fall back to your stored copy when a provider is unavailable. The reply says which one it used, and how fresh and complete that data was.

05

They search and read the web

No setup and no extra connector. An agent looks something up, tells you which pages it used, reads a bounded number of them, and treats what it finds as information rather than instructions.

06

They hand back the file

Calculations run over real data and come back as a spreadsheet, a PDF, or a document in the conversation that asked for it, with the source data attached.

The rest of the box

The tools the company runs on.

Everything below belongs to a department or a person, with an owner and a scope.

Task boards Lanes that match the real workflow, with owners, dates, subtasks, comments, attachments, property links, and reusable templates. My Tasks collects one person's work into a single list.
Email and calendar Read, reply, send, create events, and check availability from Google Workspace or Microsoft 365, scoped to the right department or person.
Automations Flows built from email and task events, with conditions, AI steps, web research, drafts, messages, and task actions. Test one before turning it on, then inspect every run.
Box Apps Ask Engineering for an internal tool built on approved department data. Apps can save work now: task stages, notes, checklists, and governed connector writes, under per-app permissions.
Website studio Marketing can import the company site, ask for changes in plain English, compare versions, preview each one, publish, and attach a custom domain.
Marketplace Agents and skills shared by other property managers. Every install arrives as a draft with its full instructions and required connectors visible first.
MCP access Create a revocable personal token and use approved Box data from Claude Code, Codex, Cursor, Claude Desktop, or another MCP client. Access follows the member who created it.
Portable export Owners can build a machine-readable archive of shared Box data. Connector secrets, Personal AI, direct messages, and private group chats stay out of it.
Oversight Adoption receipts, app permissions, connector audiences, model choice per department, and support debug IDs, without opening anyone's private conversations.
