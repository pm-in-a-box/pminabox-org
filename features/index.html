Product tour

Everything the team needs to run the work.

PM in a Box combines the daily tools of a property management company with agents that can work from the right data and context. Each feature has an owner, a scope, and a clear place in the operation.

This tour covers the hosted beta and the desktop experience under development. The desktop app is not yet publicly released, and feature availability may change during beta.

Teamwork Work Automation Apps Data Access Control

01

Teamwork

The company has rooms. The agents work in them.

Shared work is organized by department. Private work stays with the person who owns it.

Department channels

Every department is a live chat room with messages, threads, reactions, mentions, attachments, presence, search, and voice calls. A room also owns its task board, email, calendar, automations, agents, skills, model, and connectors.

Agents you call by name

Department agents answer when they are @mentioned. They can load attached skills, inspect an approved connector, search the relevant room history, work with files, and show the tool activity behind an answer.

Direct and group conversations

Team members can send direct messages, create private group chats, and start voice calls. These conversations do not invoke department agents and remain outside shared Box exports.

Personal AI

Each person has a private AI room with its own name, instructions, skills, model, and connectors. Personal AI data does not become department data, and owners cannot open the conversation through management oversight.

The Warehouse

The cross-Box lobby gives property managers a place to share questions, answers, and useful work with the broader community while keeping company operations in their own Box.

Notifications that follow the work

Control alerts for calls, direct messages, mentions, and department activity. Supported notifications route back to the exact channel, message, task, app, or marketplace listing.

02

Work

Conversation turns into owned work.

Tasks, inboxes, and calendars live beside the discussion that created them.

Department task boards

Create lanes that match the real workflow. Assign people and departments, set dates and priority, add subtasks and comments, attach files, link properties, and move work through completion.

Reusable task templates

Save recurring checklists as department-owned templates. Applying a template creates an independent task with the current description and subtasks, so later template edits never rewrite work in progress.

My Tasks

See assigned tasks, department work, approvals, and related activity in one personal queue. A task can move between departments without losing its history or attachments.

Shared and personal email

Read threads, compose replies, and send from Google Workspace or Microsoft 365. Shared mail belongs to a department. Personal mail stays with Personal AI.

Calendar work

List and create events, update schedules, check attendee availability, and find open meeting times. Calendar access uses the same department or personal scope as email.

Files with context

Attach source material to chats and tasks. Agents can work with text, images, PDFs, Word documents, and spreadsheets within explicit size and context limits.

03

Automation

Build the repeatable part. Keep the judgment visible.

Automations are department-owned flows with a test path and a run history.

Visual flow builder

Connect triggers, conditions, AI prompts, web research, email drafts or sends, chat messages, and task actions on a canvas your team can inspect.

Test before activation

Simulate a flow without posting or emailing. AI and research steps can run against the test input so the result is visible before the workflow acts.

Agent-proposed automations

Personal AI can turn a repeated request into a reviewable automation proposal. Nothing becomes active until a person accepts the proposed flow.

Run history

Inspect what started the flow, which node ran, what it produced, and where it failed. Errors stay visible instead of being treated as successful work.

04

Apps

Build the small tool your company is missing.

Box Apps and the Website studio turn requests into reviewable, versioned software.

Box Apps

Ask the protected Engineering agent to build an internal app. Choose the home department and the exact connector data it may use. Drafts stay private until a manager publishes them.

App permissions

Set viewers, operators, and managers per app. Every action pins its target, minimum role, and original grant. Board and connector writes are audited.

Safe app data

An app receives only the fields declared on its immutable version. It never receives a session token, connector credential, or arbitrary access to another department.

Website studio

Marketing can read an existing site, create a fresh homepage, refine it with plain-language requests, compare versions, preview each one, publish, and attach a custom domain.

05

Data and connectors

Use business data without flattening its boundaries.

Each connector belongs to one department or one Personal AI. The server holds the credential.

PandaDocRead-only document and template data

Continuous connector mirrors

Supported connector data can sync into a department-owned mirror for search, agents, reports, automations, and exports. Freshness and partial coverage remain visible.

Portfolio reports

Owners can ask an agent to run a verified report recipe. Property, unit, owner, and rent-roll data produce matching PDF and spreadsheet artifacts from one immutable run.

Portable Box export

Owners can build a machine-readable archive of shared chats, tasks, configuration, membership, connector metadata, and imported business records. Missing source objects fail the export visibly.

Private data stays out

Personal AI, direct messages, private group chats, connector secrets, session capabilities, and MCP tokens are excluded from the owner-wide export.

06

Access

Use the box from the tools where you already work.

MCP access

Create a revocable personal token for Codex CLI, Claude Code, Cursor, Claude Desktop, or another Model Context Protocol client. The token acts as the member who created it.

Computer use

Pair the bundled Chrome companion to let the workspace-level browser agent navigate, list and focus tabs, click, type, capture screenshots, and extract visible page content.

Agent compute and exports

Agents can calculate over bounded data handles and create reviewable CSV, XLSX, PDF, and document outputs. Generated files return to the originating conversation.

Marketplace

Browse, test, publish, install, update, and remove community agents and skills. Listings disclose their full instructions and connector requirements before install.

07

Control

Owners can manage the company without opening private work.

People and department access

Invite members, assign roles, and grant explicit department membership. Connector audiences are visible before authorization and after setup.

Adoption oversight

See last login, last meaningful work, and content-view receipts. Hierarchical work-inbox review is audited and excludes personal conversations, email, calendars, and connector data.

Model choice by department

Select from the models available to the Box. Each department keeps its own default, while server-side routing keeps provider credentials out of the client.

Debug IDs and traces

Agent replies carry a support debug ID. If a customer shares that exact ID, authorized support can inspect the bounded run trace. Cross-Box access is restricted and audited.
