Agents can do more than draft an answer.

These capabilities are part of the PM in a Box runtime. They are registered, bounded, and visible in the conversation. They are not separate marketplace listings.

Guardrails

A tool call is a boundary, not a suggestion.

The runtime owns each tool name, input schema, effect type, timeout, and result budget. Long results are bounded before they enter the conversation.

Scoped by the roomDepartment tools use department access. Personal AI tools use the single user's access.
Visible in chatStart and result events show which skill, connector, or action the agent used.
Writes are narrowSupported writes are explicit, such as email drafts, calendar events, AppFolio notes, and declared Box App actions.
Files have limitsType, size, count, and total context budgets prevent a run from silently absorbing an unlimited attachment set.
Runs can be cancelledCancellation targets the exact reply. Queued work rechecks access and configuration before it starts.
Failures remain failuresProvider, permission, timeout, and integrity errors stay visible and do not become fabricated success.
