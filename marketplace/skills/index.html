How skills load

Give the agent less context up front.

An agent first sees the name and description of each attached skill. It loads the full instructions only when the work calls for them.

  1. 1

    Attach

    Choose the agent that owns the capability. Skills do not float outside an agent.

  2. 2

    Discover

    The agent receives a compact list of available skill names and descriptions.

  3. 3

    Load

    The agent loads the instruction body and exact approved resource paths when relevant.

  4. 4

    Inspect

    The chat shows the skill load event, so a person can see which guidance entered the run.
