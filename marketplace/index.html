Install flow

Review first. Activate last.

An install never silently becomes an active coworker.

  1. 1

    Browse or search

    Filter live agent and skill listings, sort by newest or popular, and open the full detail before taking action.

  2. 2

    Read the definition

    See the exact instructions, bundled skills, changelog, author, install count, version, and connector requirements.

  3. 3

    Choose the department

    Agent listings install into a named department. That room determines the people, data, and connectors the new draft may use.

  4. 4

    Review the draft

    The agent or skill lands as a draft. A Box owner or admin can edit it, attach it, test it, and activate it when the setup is ready.

Publish from your own Box

Share the instructions that already work for your team.

Owners and admins can package an agent with one or more skills, choose its categories and connector requirements, test the exact version in Personal AI, and submit it for review.

Approved versions are immutable. Updates include a changelog. Installing teams can compare the new definition before replacing any local edits.

Submitting content grants APM Help the distribution rights described in the Terms.
