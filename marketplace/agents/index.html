Marketplace agents

An AI coworker should have a job description.

A PM in a Box agent belongs to a department, answers when mentioned, carries a specific set of skills, and works only with the connectors available in that room.

What an agent can do

Context first, action second.

The runtime discloses skills and connector capabilities gradually, so an agent loads the details it needs instead of receiving every document and credential up front.

Understand the roomUse the exact triggering message, the relevant thread or channel history, and attached files.
Load a skillRead focused instructions and approved supporting resources when the task calls for them.
Use connected dataInspect a department connector, call a registered operation, and return evidence with the answer.
Create an outputRun bounded calculations, produce spreadsheets or documents, and attach the result to the conversation.
Propose a changeSuggest an automation, skill improvement, or Box App release for a person to accept.
Leave a traceShow tool activity in chat and attach a support debug ID to the completed reply.

Marketplace installs

The full definition is visible before install.

A marketplace agent declares its instructions, bundled skills, connector requirements, author, version, and changelog. It installs into a department as a draft.

The installing team decides when to activate it. Updates cannot silently replace local edits.
