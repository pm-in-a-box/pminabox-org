One connector, one audience

Data access has a visible boundary.

Before a connector is authorized, the setup shows who will be able to use it. The same audience remains visible on the configured connector.

Shared

Department connector

Owners and admins have shared department access. Members need an explicit grant. Every agent in that room uses the same connector boundary.

Private

Personal AI connector

Only the person who configured it can reach the connector, related email or calendar data, and the private agent room.

Portable

Export without secrets

Shared imported data can enter the owner-created Box export. API keys, OAuth tokens, cookies, session capabilities, and encrypted credential envelopes never do.

Background sync

Freshness is part of the answer.

Supported connectors maintain bounded mirrors for search, reporting, exports, and automations. Status surfaces distinguish a valid connection from a ready, current dataset.

External AI access

Use connectors over MCP.

A personal MCP token can expose the departments and registered connector tools its owner may access. Writes are limited to supported email drafts, calendar events, and AppFolio notes.
